# Pickering TSA 기능 대조

Pickering TSA 4.6.1의 공개 화면과 공식 도움말에서 확인한 항목을 ATE Studio의 기능과 대조했다. 로그인 전에는 편집 도구를 확인할 수 있었고, 프로젝트 생성·공동작업·견적 제출의 계정 절차는 공식 도움말을 기준으로 대조했다.

- [Project Manager](https://tsa.pickeringtest.com/project)
- [System Configuration Tool](https://tsa.pickeringtest.com/drawing/main/modchassis/1/0)
- [Cable Design Tool](https://tsa.pickeringtest.com/drawing/main/cable/1/0)
- [Pickering TSA 공식 도움말](https://tsa.pickeringtest.com/static-pages/knowledgebase?page=manual)

## 9050 교차 확인

1. 9050 배선 예제를 연다. 와이어링의 경로 도면에서 `PICK-01 · J1`과 `RCV-01 · A.1`을 확인한다.
2. 경로 `CBL-001`을 선택하고 경유점을 추가한다. 분기점을 만들어 경로가 그 좌표를 지나도록 지정한다. 도체·핀 편집에서 케이블의 기존 4개 핀쌍이 유지되는지 확인한다.
3. 프로젝트 관리자에서 별도 프로젝트를 만들고 현재 예제를 케이블 설계로 저장한다. 리비전, 첨부, 질의를 추가한 뒤 작업공간 반출과 재반입을 확인한다.
4. SVG와 견적 검토 ZIP을 생성한다. 경로 모양과 9050 접점은 제조사 자료의 접점 배열 및 실제 요구 신호와 대조한다.
